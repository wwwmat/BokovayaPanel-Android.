# Боковая панель

Android-приложение для быстрого запуска установленных приложений с плавающей полоски у правого края экрана.

## Сборка APK
Каждый push в ветку `main` запускает GitHub Actions. Готовый APK будет доступен в разделе **Actions → последний запуск → Artifacts** под именем `BokovayaPanel-debug`.

## Сборка локально
Откройте репозиторий в Android Studio и выполните задачу `app → Tasks → build → assembleDebug`.

## Разрешения
Для работы плавающей панели необходимо вручную разрешить приложению отображение поверх других окон. Для постоянной работы Android также показывает уведомление foreground-сервиса.

## Текущий этап
Это начальная версия проекта. Сначала проверяется корректность сборки и базовый запуск плавающей панели; настройки размеров/прозрачности, несколько отдельных панелей-каруселей и закрытие по нажатию вне панели будут добавляться и проверяться отдельными этапами.
